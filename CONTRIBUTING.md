# Guia per contribuir

Gràcies per voler contribuir a aquest projecte! Aquesta guia explica com fer-ho.

## Estil de codi

- Utilitza noms de variables i funcions descriptius.
- Indenta amb 4 espais (no tabuladors).
- Comenta el codi complex o no evident.
- Mantén les funcions curtes i amb una única responsabilitat.

## Pull requests

1. Fes un fork del repositori i crea una branca per a la teva feature.
2. Fes commits petits i amb missatges clars.
3. Assegura't que el codi funciona abans d'enviar.
4. Obre una pull request descrivint què canvia i per què.

## Report d'issues

- **Títol** breu i descriptiu.
- **Descripció** del problema.
- **Passos per reproduir-lo**.
- **Comportament esperat** i **comportament real**.
